# Stats107GroupProject
**00_requirements.R** includes the roper packages needed to run the code used to prep and process data for this project.

**nsduh_table1_sex.csv** Includes the dataset used for the project. Including information on different age groups, sex, and outcomes regarding opiod use.

**cleaning_and_processing.rmd** Processes the data involved, and prepare it for your project analyzing differences in substance-related overdose rates across demographic groups.

**02_funct_Plots.R** Code used to create data plots by sex type, count, etc., builds the male vs. female visualizations. Generates the graphs used in final report.

**31_DataVisualization.Rmd** Summarizes and explains the data plots, and explains how they support our hypothesis

**FinalReport.Rmd** Written report on project findings and hypothesis. Including visualizations and summarizations of data as a whole. Also includes contribution list and abstract.

**README.md** Provides an overall guide to files

**figures** Folder containing our three graphs made from the data
  **fig1_prevalence_by_sex.png** shows the comparison of the SUD/MDE prevalence between male and female
  **fig2_counts_by_sex.png** shows the estimated number of people with SUD/MDE between male and female
  **fig3_sex_difference.png** Shows the difference in prevalence between males and females
